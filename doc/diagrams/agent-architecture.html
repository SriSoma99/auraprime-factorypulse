How one incident travels from a machine to a verified fix. The real-time path never depends on a model, agents cooperate through one shared incident record, and every action is advisory, approved by a person and audited.

How agents talk to each other

Inside the workspace: shared state

Roles never message each other. Each reads and writes its own part of the incident record, and the orchestrator decides who runs next. Every step is stored, so a diagnosis can be replayed, audited and resumed after a restart.

To tools: MCP

Role agents reach plant data through scoped, read-only tool servers (draft-only for work orders). Internal and external tools share one contract, so default-deny and audit apply to both.

To outside agents: A2A, optional

An agent-to-agent protocol appears only at the external edge, for example an OEM's own agent asking for a diagnosis. It lives in the Full edition as an adapter and is never used between internal roles.

Deliberately constrained

No agent can change equipment or approve its own work. Routing is deterministic, not chosen by a model.

No chat store yet

An operator copilot would add a conversation record later, under the same redaction and evidence rules.
