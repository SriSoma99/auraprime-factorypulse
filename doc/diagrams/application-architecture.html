AuraPrime FactoryPulse Application Architecture

Every application component (APP-xx) by criticality tier, with the interfaces (INT-xx) and Kafka topics between them. Telemetry flows one way from the plant to the platform; the alert path never waits on a model, and every action stays advisory, human-approved and audited.
