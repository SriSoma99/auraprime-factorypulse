  • Approve and reject exist only in a human session with the required role (invariant 2). API keys and agent tokens see the screen read-only, with the reason stated.

  • Escalation and expiry follow the timers in 03 section 11; timer lengths are configuration, not fixed in the design.
  • Open question: should "undo" exist for a short window after approving? The current design says no and asks for a new draft instead.
